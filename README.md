> 🎯 Project Objectives:
> 
> Build an e-commerce platform using a microservices architecture
> Containerize all services with Docker
> Automate build and deployment using CI/CD (Jenkins, ArgoCD)
> Provision AWS infrastructure (EKS, ECR) with Terraform
> Monitor the system using Prometheus and Grafana
> 📦 Project Scope :  microservices (web, database, payment, search), CI/CD pipelines, Kubernetes deployment with auto-scaling, monitoring and alerts
> 
> 📅 Project Plan (5 Weeks)
> Week 1: Planning, microservices, Dockerfiles
> Week 2: Terraform, AWS (EKS, ECR)
> Week 3: Jenkins pipelines, Kubernetes manifests
> Week 4: ArgoCD, auto-scaling, rollback
- Week 5: Monitoring, testing, documentation, delivery
